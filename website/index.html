AWS Cloud Lab

Built for Onified.ai by Yash Gaur

A hands-on AWS cloud infrastructure and operations project built to demonstrate practical cloud engineering skills.

Currently implemented

  • AWS VPC and subnet architecture
  • Internet Gateway and routing
  • EC2 infrastructure
  • IAM role and instance profile
  • AWS Systems Manager administration
  • Terraform Infrastructure as Code
  • Linux systemd service management
  • NGINX web server
